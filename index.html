Why we exist

Mission, vision, belief

Mission

Help people acquire, retain and confidently apply practical skills for life.

Vision

A world where practical knowledge is never forgotten.

Core belief

Knowledge only has value when it can be recalled and applied at the moment it matters.

What we believe

Learning is not a phase of life

People forget because the world does not remind them. Practical skills deserve better tools than textbooks. Technology should augment human memory, not replace it.

Learning

  • Learning never ends.
  • Everyone is capable of learning.
  • Practical skills deserve the same respect as academic knowledge.
  • Learning should create confidence.

Memory

  • Knowledge forgotten is knowledge lost.
  • Memory requires maintenance.
  • Small moments repeated beat large study sessions.

Technology

  • Technology should amplify people.
  • Technology should never replace understanding.
  • AI should help people think, not think for them.

Motivation

  • People want to improve.
  • Progress motivates more than rewards.
  • Consistency beats intensity.

Community

  • People learn better together.
  • Sharing knowledge benefits everyone.
  • Communities preserve expertise.

Trust

  • Trust takes years to build.
  • Users trust products that consistently help them.
  • We never sacrifice trust for growth.

First product

SailPrep

SailPrep is the first product proving that vision — not the company itself. Exams are an entry point and motivation, not the end goal. We build for real life: flashcards, quizzes, and reminders so sailing knowledge is there when it matters on the water.

Boundaries

What we refuse to become

These lines exist so we can say no when an opportunity does not match who we are.

  • We refuse to build addictive products.
  • We refuse to optimize for time spent instead of value gained.
  • We refuse to sacrifice accuracy for speed.
  • We refuse to overwhelm users with unnecessary features.
  • We refuse to lock users into our ecosystem.
  • We refuse to build products we would not personally use.
  • We refuse to compromise trust for growth.
  • We refuse to chase trends that do not align with our mission.
